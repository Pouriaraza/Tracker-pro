# Site Tracker - Starter

A minimal Next.js + Tailwind starter that reproduces the public layout of the target site.

Prereqs:
- Node.js (16+)

Run locally (PowerShell):
```
npm install
npm run dev
```

Open http://localhost:3000

Files created:
- `package.json`, `pages/`, `components/`, `styles/`, Tailwind config

Next steps:
- Run the commands above to install dependencies and start a dev server.
